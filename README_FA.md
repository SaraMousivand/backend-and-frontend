# CodeQuest — پروژه‌ی آموزشی فرانت‌اند و بک‌اند

## پیش‌نیازها
- Python 3.9 یا جدیدتر
- VS Code
- اینترنت فقط برای بارگیری اولیه‌ی Flask و فونت آنلاین (خود برنامه برای اجرا به API خارجی نیاز ندارد)

## اجرا در ویندوز
1. پوشه‌ی `CodeQuest` را در VS Code باز کن.
2. از منوی Terminal گزینه‌ی New Terminal را بزن.
3. محیط مجازی بساز:

   ```powershell
   py -m venv .venv
   ```

4. محیط مجازی را فعال کن:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   اگر PowerShell اجازه‌ی فعال‌سازی نداد، می‌توانی بدون فعال‌سازی هم از این دستور استفاده کنی:
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe app.py
   ```

5. Flask را نصب کن:

   ```powershell
   python -m pip install -r requirements.txt
   ```

6. برنامه را اجرا کن:

   ```powershell
   python app.py
   ```

7. در مرورگر برو به: http://127.0.0.1:5000

برای متوقف کردن سرور، در ترمینال `Ctrl+C` را بزن.

## فایل‌ها چه کار می‌کنند؟
- `app.py`: بک‌اند پایتون، مسیرهای وب، بررسی پاسخ و SQLite.
- `templates/index.html`: ساختار صفحه.
- `static/style.css`: رنگ‌ها، فاصله‌ها و طراحی واکنش‌گرا.
- `static/app.js`: کلیک‌ها، دریافت سؤال‌ها از سرور و به‌روزرسانی صفحه.
- `requirements.txt`: فهرست بسته‌های موردنیاز.
- `codequest.db`: به‌صورت خودکار هنگام اجرای برنامه ساخته می‌شود و امتیازها را نگه می‌دارد.

## نکات آموزشی
- مرورگر پاسخ درست سؤال‌ها را دریافت نمی‌کند؛ بررسی پاسخ در بک‌اند انجام می‌شود.
- در SQL برای مقادیر کاربر از `?` استفاده شده تا مقادیر به‌صورت پارامتر ارسال شوند.
- این پروژه برای نمایش محلی و آموزشی است. `debug=True` و کلید نمایشی نباید در یک وب‌سایت عمومیِ منتشرشده استفاده شوند.
- امتیازها در فایل محلی `codequest.db` ذخیره می‌شوند؛ جدول قهرمان‌ها بین اجراهای برنامه روی همین کامپیوتر باقی می‌ماند.
